# paint.net window notes

These notes describe the controls in paint.net's documentation. The OpenPainter mockups use new drawings and Mac window controls.

- Menu bar: paint.net has File, Edit, View, Image, Layers, Adjustments, and Effects menus. Four utility icons show or hide Tools, History, Layers, and Colors; Settings and Help follow them. OpenPainter adds a Window menu for the panel commands and uses the Mac menu bar. Source: [Menu Bar](https://paint.net/doc/latest/MenuBar.html).
- Main window: the title names the image and marks unsaved changes with an asterisk. The image list contains a thumbnail for each open file, highlights the current file, supports click to switch and drag to reorder, and marks unsaved thumbnails with an asterisk. The canvas sits in a gray editing area. Source: [Main Window](https://paint.net/doc/latest/MainWindow.html).
- Toolbar rows: the first row holds New, Open, Save, Print, Cut, Copy, Paste, Crop, Deselect, Undo, Redo, Pixel Grid, and Rulers. The second row starts with a tool picker and then shows options for the active tool. Brush width has increment and decrement controls. Rasterization toggles antialiasing; a separate split button chooses the tool blend mode. Source: [Tool Bar](https://paint.net/doc/latest/Toolbar.html). - Status bar: left side gives tool tips or tool status; a progress bar appears while an effect or adjustment renders. The right side shows image size, cursor position, measurement units, an editable zoom percentage, a quick size toggle, and a zoom slider. Source: [Status Bar](https://paint.net/doc/latest/StatusBar.html). OpenPainter's selection size is an added field in these mockups.
- Tools: the floating window has tool icons, highlights the active tool, and gives shortcut hints on hover. Its groups cover selection, move, view, fill, drawing, photo, text, and shapes. F5 toggles it; the title bar can be dragged. Source: [Tools Window](https://paint.net/doc/latest/ToolsWindow.html).
- Colors: primary and secondary swatches sit by a color wheel and a palette. More expands the panel to RGB, HSV, opacity, and editable hex values; the full 96-color palette appears when expanded. F8 toggles the window, and its title bar can be dragged. Source: [Colors Window](https://paint.net/doc/latest/ColorsWindow.html).
- Layers: the window lists the active layer with a highlight and supports hidden layers, blend modes, opacity, and drag reordering. Buttons add, delete, duplicate, merge, move, and open properties. F7 toggles the window. Source: [Layers Window](https://paint.net/doc/latest/LayersWindow.html).
- History: each action becomes a row. Clicking a row jumps to that state. Undone later rows turn gray; Undo and Redo buttons sit below the list. F6 toggles the window. Source: [History Window](https://paint.net/doc/latest/HistoryWindow.html).
