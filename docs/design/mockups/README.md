# Main window directions

Open each HTML file at 1440 × 900. Use the appearance button to switch between light and dark. Add `?theme=dark` to open the dark version directly. Every icon and the coastal image is drawn in the HTML; the pages load no outside files.

## Classic

[Open Classic](classic.html) · [light PNG](png/classic-light.png) · [dark PNG](png/classic-dark.png)

This follows paint.net's rows: common commands, active tool options, thumbnail strip, and canvas. The four panels float near the corners, with Mac traffic lights and quieter borders. Risk: panels cover image edges when the window is small.

## Unified toolbar

[Open Unified toolbar](unified.html) · [light PNG](png/unified-light.png) · [dark PNG](png/unified-dark.png)

This keeps paint.net's image strip, tool settings, status fields, and all four floating panels. A taller Mac title and toolbar group commands above translucent utility windows. Risk: the top band uses more height, so the image has less room on a short display.

## Compact pro

[Open Compact pro](compact.html) · [light PNG](png/compact-light.png) · [dark PNG](png/compact-dark.png)

This keeps the same four panels, tool options, thumbnails, and F5–F8 toggles. Panels rest against the canvas edges by default; dragging any panel header detaches it into a floating utility window in the planned app. Risk: narrow panels squeeze labels and the edge layout leaves less canvas width. The mockup shows the resting state and labels the drag action; its static HTML does not implement panel dragging.
