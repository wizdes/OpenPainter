# Adversarial review of the three mockups (fresh Opus reviewer, 2026-10-24)

Summary of the findings root accepted (full text in the session transcript):
1. Compact docks panels, against the user's floating-panel decision.
2. At 1280x800 all three either cover the image or overlap panels (Classic: Tools/Colors overlap; panels cover 17-28 px of the image). No overlap rule exists.
3. F5-F8 are media keys on Mac laptops; add a second shortcut set.
4. Unified is not a real unified toolbar (two rows, 109 px) and its 470 px options box cannot hold Text, Wand or Gradient options.
5. The three HTML files are byte-identical except geometry; Classic and Unified are one layout with different spacing.
6. Mac conventions: no appearance button in the title bar, title shows only the document name with the Edited mark, close buttons on the left of utility panels, every visible panel's toggle pressed, distinct drawn icons, no "Select" button (paint.net has Deselect).
7. Accessibility: undone History rows 2.49:1 / 3.23:1; unsaved "*" 2.6:1 dark; radio-like layer visibility glyphs; many targets under 24 px; dark panels 1.45:1 against the stage.
8. Gaps vs paint.net: toolbar missing Print, Cut, Copy, Paste, Deselect, Pixel Grid, Rulers; options row lacks a tool picker and -/+ for width; Tools window is a narrow tall strip in paint.net (to verify); History above Layers (to verify); Colors opens compact (to verify); panels fade when the pointer leaves (to verify).
9. Wasted space: 83 px image strip mostly empty.
10. Unified's translucent blur changes panel colors over photos.
11. Palette is muddy compared with paint.net's saturated default.
Pick: Classic, with a unified toolbar row (52 pt), 36 pt options, 60 pt strip, 24 pt status bar, narrow Tools strip, compact Colors, snapping and overlap rules, accessibility fixes, saturated palette.
