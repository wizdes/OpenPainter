# Keyboard shortcuts

Generated by `KeyboardAccessibilityTests.testShortcutTableIsGeneratedAndNoKeyClashes` from
`tests/catalog/paintnet-5.1-menus.toml` (the menus) and `KeyboardShortcuts.canvas` in
`mac/OpenPainterKit/Sources/Shell/KeyboardShortcuts.swift` (the other keys). Do not edit by hand.

The rule: paint.net's Ctrl becomes ⌘ and Alt becomes ⌥. Where that would take a standard Mac key,
the Mac key wins and the note says so. Sources: paint.net's Keyboard & Mouse Commands page
(https://www.getpaint.net/doc/latest/KeyboardMouseCommands.html) and Apple's Mac keyboard shortcuts
(https://support.apple.com/en-us/102650).

## Mac differences

- F5 to F8 send brightness, dictation or media keys on Apple keyboards unless fn is held or "Use F1, F2, etc. keys as standard function keys" is on. ⌥⌘1 to ⌥⌘4 toggle the same panels.
- Buttons, popups and custom controls take focus with Tab only while Keyboard navigation is on (System Settings > Keyboard; ⌃F7 toggles it). Text fields always take focus.
- ⌃` and ⇧⌃` move focus between the image window and the shown panels (Window > Next Panel). ⌘` stays with macOS (next window), and ⌃F6 (focus the floating window) stays with macOS.
- paint.net shortcuts that would take a Mac key: see the Note column above (Rotate 90° Clockwise, Merge Layer Down, Toggle Layer Visibility, Rotate / Zoom, Redo, Exit).

## Not in this version

| paint.net key | What it does | Why |
| --- | --- | --- |
| Alt, Alt + letter | Menu access keys | Mac menus have no access letters; ⌃F2 moves focus to the menu bar (macOS) |
| Alt+T | Open the tool dropdown | The options row's tool popup is reached with Tab |
| PgUp, PgDn, Home, End (and Shift, Ctrl) | Scroll the canvas | Follow-up; scroll with the trackpad or the Pan tool |
| Space + Arrows | Pan with the keys | Follow-up |
| Ctrl+Shift+F5 to F8 | Reset one window | Window > Reset Panel Layout resets all four |
| Ctrl+1 to 9, Alt+1 to 9 | Switch to image number N | Follow-up; ⌥⌘1 to 4 toggle the panels |
| Ctrl+Shift+PgUp, PgDn | Move the image tab left or right | Follow-up; drag in the image strip |
| Alt + − | Image context menu | No image context menu in this version |
| A, Shift+A | Cycle shapes | The Shapes tool is not built yet |
| , . / | Line / Curve caps and style | The Line / Curve tool is not built yet |
| Ctrl+Alt+Shift+~ | Diagnostic aid | Windows only |
| F1 | Online documentation | Help > OpenPainter Help (⇧⌘?) is off until the help pages exist |
