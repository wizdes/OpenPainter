## What this changes

1. **Captures need the user's copy closed.** Portable paint.net writes to `%LOCALAPPDATA%\Paint.NET`, and it cannot run as `agent`. So it must run as `yjli`, where it shares that folder with the user's copy. Section 3.2 of the plan says captures then run only while the user's copy is closed. W4 follows this rule. It can still try a capture path with no paint.net window, if one exists.
2. **The pin needs a clean unpack before W4.** The `agent` run left files in `C:\agent-work\pdn-5.1.12`. Also, `Authenticated Users` can change files in `C:\agent-work`, which is wider than the memory note said. W4 unpacks it again from the ZIP, checks the SHA-256, and takes write access away from `agent`.
3. **GPU tests can run on builders.** Effects and GPU matrix work does not need a visible desktop.

## Traps

- A .NET 10 program built here looks for the system .NET 9 unless `DOTNET_ROOT` points at `%USERPROFILE%\.dotnet10`.
- `lms ps` starts LM Studio. I ran it once by mistake, then stopped that process tree by PID. `preflight.ps1` never calls it.
- If LM Studio is open with its server off, the preflight cannot see loaded models, so it fails with "cannot determine".
- A stream is detected through NVENC sessions from `nvidia-smi`, so another program using the encoder also counts as busy.
- The runner counts cargo output as edits outside owned paths, even with a gitignored folder. Pass `--cache engine/target/`, and create the folder first.
- `.gitattributes` keeps text as LF. Line endings on existing files did not change.
