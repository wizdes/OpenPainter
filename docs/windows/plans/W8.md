# W8: Panels and shortcuts

Tier 3: this is new UI in the app that every later UI milestone builds on. Budget: 20 agent hours, note to the user at 30. Needs: W7.

W8 fills the four empty panels and adds Layer Properties, palettes and the Windows shortcuts. Each panel works against the engine through the C bridge. The Mac app is the reference for layout, order and words.

## What changes

| Stage | Item | Result |
| --- | --- | --- |
| 1 | `launch paint` | The unreliable harness check gets a cause and a fix. It did not pass in 11 of 53 runs at W7. |
| 1 | History, Layers, Layer Properties | Every action works on the engine: select, add, delete, duplicate, merge, move, visibility, opacity, blend mode, name, undo and redo through History. Pictures of layers come from the engine. |

## Done-test

Each item comes from a real run, or is reported as NOT RUN.

1. Every panel action is tested headless, against the real engine, not a stand-in.
2. A test lists every panel action from the Mac's panel sources. An action on the Mac with no Windows test fails by name.
3. Shortcuts match the Mac's with Ctrl for Cmd, with 0 unexplained differences. A written table holds each difference and its reason, and a test holds the table.
4. Focus rules follow `Shell/FocusRouter.swift`, each rule with a test.
5. Color math passes the Swift vectors.
6. Root looks at one real-window shot per panel, light and dark.
7. `launch paint` passes 50 of 50 `pixels` runs, or the report names the cause and why it stays open.
8. `cargo xtask check --tier fast` passes. `--tier milestone` is run and its result written down. `--tier window` is run when the PC is quiet.
9. A fresh review runs at the end. After Nov 4, 9:32 PM, Astra as well.

## Not in this version

- Tools that change pixels on the canvas. W9 does those. A panel may call engine commands that change layers, such as add layer or set opacity.
- Open, Save and Recent. W10 does those, so tests load pictures through the test hook.
- Effects menus. W11 does those.
- Text tool options beyond binding. W13 does the text tool.
- Translations and Narrator. W17 and W18 do those.
