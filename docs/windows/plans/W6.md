# W6: Windows look and icons

Tier 3: this look and icon set feed all later UI work, W7 to W20. Budget: 6 agent hours. Needs: W5.

W6 draws one Windows version of the Mac window with Avalonia, the stack W5 chose. It puts that picture next to real Mac app shots. It also gives every Mac icon a Windows icon with a license record.

The Mac app is the reference for layout, panels, menus, dialogs and shortcuts (user decision, 2026-11-02). paint.net is not a UI reference, and none of its icons are used.

## What changes

| Item | Owner | Result |
| --- | --- | --- |
| `tools/ui-look/app` | Builder | A small Avalonia project that draws fixed scenes, with no engine and no working tools. It writes each scene to a PNG by the headless Skia renderer. |
| `tools/ui-look/tests` | Builder | Checks for the icon records and that each scene draws. |
| `windows/assets/icons/` | Builder | One SVG for each meaning. |
| `windows/assets/icons/LICENSES.md` | Builder | The MIT text and copyright of the icon package, with its name and version. |
| `docs/windows/icons.toml` | Builder | One row per Mac icon: Mac symbol, where the Mac uses it, Windows file, source, license. |
| `docs/windows/w6-look.md` | Builder starts, root finishes | Each Windows change, why, and the critique findings with what was done about each. |
| Side-by-side page | Root | A private page with the Mac shots and Windows renders together. |
| Critique | Root starts | Astra through the runner, and a fresh native reviewer who does not see the builder's reasons. |

## Scenes

Each scene comes in light and dark, at 1376 by 928 layout pixels (the Mac shot's size at 2x) and at 2x scale:

1. Main window with Paintbrush selected, 2 layers and 7 history rows.
2. Text tool with its options row.
3. Ellipse selection with its options row.
4. The Curves dialog.
5. The Hue / Saturation dialog.
6. The Colors panel, expanded.

## Done-test

- All 6 scenes render in light and dark, and root has looked at each one.
- Every SF Symbol name in the Mac app's source has a row in `icons.toml`. A test reads the Mac source and fails on any missing row.
- Every row names an SVG that exists, and a source and a license from an allowed list. A test fails on anything else.
- `w6-look.md` lists each Windows change and why.
- Both critiques finished, and root recorded a decision on each finding.

## Not in this version

- Working tools, a real canvas, engine calls or saved settings. W7 and later do that.
- The menu's contents. W7 checks the menu order against the Mac.
- A choice between several looks. The Mac app is the reference, so W6 draws one version.
- An app icon. W19 does that.
