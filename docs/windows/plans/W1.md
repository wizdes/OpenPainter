# W1: engine files and tests

Tier 3: this changes file storage code that holds users' work. Budget: 10 agent hours. Needs: W0.

## What changes

The engine compiles on Windows and its file code works there. Unix-only tests get ported, so Windows runs what the Mac runs.

| Area | Change |
| --- | --- |
| `op-core/src/tiles.rs` | Positional reads work on Windows. `seek_read` moves the file cursor, so a shared handle must not rely on the cursor. |
| `op-engine/src/recovery.rs` | Folder sync is a no-op on Windows only if that is proven safe, or uses a handle opened with `FILE_FLAG_BACKUP_SEMANTICS`. Atomic replace uses `ReplaceFileW` or `MoveFileExW` with `MOVEFILE_WRITE_THROUGH`, with bounded retries when antivirus holds a file. Each retry limit is a named constant, and a final failure is shown to the caller. |
| Paths | Drive letters, UNC and long paths in any code that builds or checks a path. |
| `op-ffi` | The DLL builds with the C interface exported. |
| `lcms2` panic | A damaged ICC profile gives an error, not a crash. A test uses the damaged profile. |
| Mandelbrot | Find the cause of the 23-level difference. Report it. Fix it only if the fix keeps the Mac's results. |
| Tests | Port `opaint_limits`, `release_review`, `recovery_fixes`, `huge_document`, `low_disk`, the fuzz driver and `capped_alloc`. `views` and `live_stroke` wait for W3. |

## Done-test

1. `docs/windows/test-counts.md` lists every test file with its `#[test]` count in the source and the count that ran on Windows. Every difference has a reason. Mac runtime counts are NOT RUN until decision 2 or a Mac session.
2. All non-GPU tests pass, except ones named as waiting for W2 (folder rename with an open file inside) or W3 (GPU). Each waiting test is listed with its failing line.
3. `cargo check` on `aarch64-apple-darwin` passes for the workspace, or the blocker is named. Unix code paths keep the same behavior.

## Not in this version

- The recovery folder redesign. That is W2.
- The GPU backend, DX12 view host and color table. That is W3.
- Any change to effect output, unless the Mandelbrot cause requires it and the Mac's results stay the same.
