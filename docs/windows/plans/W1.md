# W1: engine files and tests

Tier 3: this changes file storage code that holds users' work. Budget: 14 agent hours. Needs: W0.

## What changes

The engine compiles on Windows and its file code works there. Unix-only tests get ported, so Windows runs what the Mac runs.

| Area | Change |
| --- | --- |
| `op-core/src/tiles.rs` | Positional reads work on Windows. `seek_read` moves the file cursor, so a shared handle must not rely on the cursor. |
| `op-engine/src/recovery.rs`, `op-formats/src/opaint.rs:258`, `op-engine/src/document_file.rs:97` | The last two are the user's real saves. Folder sync is a no-op on Windows only if that is proven safe, or uses a write handle opened with `FILE_FLAG_BACKUP_SEMANTICS` (a read handle gives "Access is denied" on `sync_all`, proven 2026-11-01). A test checks what a save keeps of the original file. The swap is one atomic rename, never `ReplaceFileW`, which leaves a moment with no file under the name. Details are copied onto the temporary file first, with bounded retries when antivirus holds a file. Each retry limit is a named constant, and a final failure is shown to the caller. |
| Paths | Drive letters, UNC and long paths in any code that builds or checks a path. |
| `url_path` in `recovery.rs` | A real `file:///C:/x` becomes `/C:/x`, and the metadata call fails. `older_than_file` then says the record is safe, so Recover can write over a newer file. Tests use real `file:///C:/` and UNC URLs, and a URL that cannot be read must not count as "not stale". |
| Manifest name check, `recovery.rs:481` | Bans `\` as well as `/`. |
| `op-ffi` | The DLL builds with the C interface exported. |
| `lcms2` panic | A damaged ICC description does not crash. Only the name falls back, because a valid profile with a surrogate pair in its name panics the same way on Windows. A test uses the damaged profile. |
| Mandelbrot | Find the cause of the 23-level difference. Report it. Fix it only if the fix keeps the Mac's results. |
| Tests | Port `opaint_limits`, `release_review`, `recovery_fixes`, `huge_document`, the fuzz driver and `capped_alloc`. `low_disk` mounts a real disk through `hdiutil`, and a Windows disk image needs administrator rights, so it reports NOT RUN here and W19 covers low disk. `views` and `live_stroke` wait for W3. |

## Done-test

1. `docs/windows/test-counts.md` lists every test file with its `#[test]` count in the source and the count that ran on Windows. Every difference has a reason. Mac runtime counts are NOT RUN until decision 2 or a Mac session.
2. All non-GPU tests pass, except ones named as waiting for W2 (folder rename with an open file inside; `recovery.rs:618` blocks every new record) or W3 (GPU), and Mandelbrot if its fix would change the Mac's bytes. Each is listed with its failing line. Mandelbrot then goes on the user's list.
3. `cargo check` on `aarch64-apple-darwin` runs for the crates it can reach. `lcms2-sys` needs a C compiler for that target, so a full Mac check waits for a Mac session and is listed as owed.
4. A fresh review of this change.
