# W0: machine and test setup

Tier 3: this starts a new subsystem and sets the rules that later test results depend on. Budget: 6 agent hours. Needs: decision 1, which is done (root reaches `agent` with `ssh agent@127.0.0.1`).

## Who does what

Root does the machine work and runs everything that touches a real window or paint.net. One Sol builder writes the code.

| Item | Owner | Result |
| --- | --- | --- |

| Pinned paint.net | Root | `paint.net.5.1.12.portable.x64.zip` from `github.com/paintdotnet/release`, unpacked to `C:\agent-work\pdn-5.1.12`. SHA-256 `d5ae7043f2fb9d365b48dfe243a2aca1c74924de99b04b6445916c95354aefa3`. |

## `preflight.ps1`

The script takes `-Level fast|milestone|window|checkpoint|speed` and has no side effects. It prints one line per check and ends with `PREFLIGHT: PASS` or `PREFLIGHT: FAIL (reasons)`. It exits 0 on a pass and 1 on a fail.

- Every level: .NET 10 at `%USERPROFILE%\.dotnet10`, `cargo`, at least 40 GB free on C:.
- `window` and above: the desktop is unlocked, and the session is the user's desktop session, not SSH. A failed check prints `UI TESTS: NOT RUN (reason)` and fails.
- `checkpoint` and `speed`: the paint.net pin is present with the right `paintdotnet.exe` file version, 5.112.9563.32325. Sunshine has no active stream and LM Studio has no model running. If the script cannot tell, it says so and fails.
- It never starts, stops or focuses any program.

## Done-test

1. `preflight.ps1 -Level fast` passes as `agent`, and `-Level window` prints NOT RUN and fails over SSH.
2. The headless Avalonia test passes as `agent` over SSH.
3. `cargo test` passes for `xtask` on Windows. `cargo xtask check --tier window` and `--tier speed` print NOT RUN for each unbuilt part and fail.
4. `docs/windows/probes/W0.md` says what each probe found, including the hidden desktop, GPU as `agent`, and the second paint.net copy.
