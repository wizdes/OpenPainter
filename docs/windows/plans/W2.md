# W2: recovery redesign

Tier 3: this changes the code that protects unsaved work. Budget: 10 agent hours. Needs: W1, closed.

## The problem

Windows refuses to rename a folder while a file inside it is open. Recovery keeps `owner.lock` open inside each record folder and renames that folder at `recovery.rs:618` (`create_locked`), `:659` and `:677`. So on Windows no record folder can be created, and 28 tests fail for this reason.

A second problem: a clean close with another reader holding a file inside the folder also blocks the rename. The manifest delete is the real commit point (`delete_record`, `scan`), so the rename may not be needed on Windows.

## What changes

1. `docs/ARCHITECTURE.md` changes first and says the new design.
2. The lock file moves outside the record folder, so nothing inside it stays open.
3. No folder rename happens while anything inside is open. Creating a record no longer needs the rename-into-place trick on Windows, or the design states what replaces it.
4. A new same-file check for the lock. A brief failure to open the lock must not read as a lost lock.
5. A `TerminateProcess` kill test on Windows.
6. Mac and Linux behavior stays the same: same results, same safety. Records in the current layout, with `owner.lock` inside, still read. If this needs an existing test rewritten, stop and report it. Root asks the user.
7. Port `item5_a_failed_clean_up_is_reported_and_retried` in `recovery_fixes.rs` to Windows, for example with a no-share handle to make the delete fail.
8. `tests/recovery.rs:259`, `:261` and `:293` assert the Unix text "No space left". On Windows they accept the Windows disk-full text, through a Windows-only branch. The Unix assertion stays.

## Done-test

1. Every recovery test listed as waiting for W2 in `test-counts.md` passes, including `huge_document`, which is run by hand.
2. Kill before, during and after a record write recovers, on Windows.
3. A clean close with another reader holding a file leaves no false recovery offer.
4. A record in the old layout still reads.
5. Fresh review. The Mac run is NOT RUN, and is listed as owed until a Mac session.
