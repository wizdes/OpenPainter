# W7: App shell and canvas

Tier 3: this is the new Windows app that every later UI milestone builds on. Budget: 18 agent hours. Needs: W5, W6, the `xtask` level fix.

W7 makes the real program in `windows/`: a window with the engine's canvas, the strip, the status bar, the command row, empty panels and the menus. Zoom and Pan work. Nothing else edits a picture yet. The Mac app is the reference for layout, order and words.

## Rules from W5 and W6

- The canvas runs at full rate on its own thread. Nothing that needs full rate may use Avalonia's UI frame callback, which W5 measured at 41 to 44 per second.
- The canvas is a custom window class, because a `STATIC` child passes the mouse through. Keep the Tab handoff from W5.
- Avalonia cannot draw over the native canvas. Overlays go through `op_view_set_overlay`. Popups and panels are their own top-level windows or sit beside the canvas, and W7 proves this on a real window.
- A `Border` with both `BoxShadow` and a child draws the child at the wrong scale in a bitmap. Keep the shadow on its own `Border`.

W7 settles these from `w6-look.md`:

1. The real caption behavior: Snap Layouts on maximize, the red hover on close, the inactive tint. The title row holds the menus, so this needs a real hit-test check.
2. Whether panels can leave the window. Default, unless a real-window test rules it out: panels are top-level tool windows owned by the main window, because the Mac's panels are separate windows and an owned window can sit over the canvas.
3. The options row's "more" button opens the rest, and the row also scrolls sideways.
4. Icons on whole pixels, with 16 px art where an icon draws at 16, checked at 100% scale.
5. The title text includes the app name, and dialogs can be dragged.

W8 settles Alt and access keys, the hover, press and focus scene, and Ctrl+Y.

## Done-test

Each item comes from a real run, or is reported as NOT RUN.

1. A 24 MP PNG, loaded through a test hook because Open comes in W10, pans over a 30 s trace at an average of 59 fps or more with no stall over 50 ms on the RTX.
2. The canvas is checked by reading real pixels back, because the W3 test program passes on a black frame.
3. The color check passes on the live window.
4. Menu order and words match `opcli dump-catalog`, with Ctrl for Command.
5. The DLL's exports are checked by name against the bridge.
6. Layout matches the W6 pictures: root looks at one real-window shot per screen, light and dark, at 100% and 200%.
7. `cargo xtask check --tier milestone` passes. `--tier window` passes when the screen is free.
8. Root writes down whether the 15 overlay hours in `w5-overlay.md` still fit.
