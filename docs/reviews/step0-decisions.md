# Step 0 review: decisions

Two independent reviews of the plan ran on 2026-10-24: Astra (Codex `gpt-6-astra`, full report in `step0-astra.md`) and a fresh Claude Opus 5.5 reviewer. They agreed on the main problems, and several findings were proven by measurement. Root accepted the findings below and changed `ARCHITECTURE.md` and `MILESTONES.md` to match.

## Accepted

| # | Finding | Evidence | Decision |
|---|---|---|---|
| 1 | paint.net 5.0 and 5.1 rewrote most effects (Gaussian gained gamma, Motion uses a Gaussian kernel, Median became Median Blur, Unfocus was removed, Edge Detect and Sharpen were rewritten, many distortions changed). A 3.36 port cannot match 5.1 captures within ±1/255. | blog.paint.net 5.0 and 5.1 notes; OpenPDN `GaussianBlurEffect.cs` uses a tent kernel | Each operation gets a row in a committed target table (`tests/oracle/targets.toml`, made in M02): target behavior (`legacy-3.36` or `pdn-5.1`), oracle source, tolerance rule, working space. Ported OpenPDN files are used only for `legacy-3.36` rows. |
| 2 | One blanket "premultiplied f32 then round" rule cannot match paint.net's integer blend. Opus measured 84% of 200,000 pairs off by 1 and a worst case of 41/255 in straight color at alpha 1. Astra showed 251 vs 249. | Script runs by both reviewers on `UserBlendOps.Generated.cs` | Every op has an explicit arithmetic contract (alpha form, working space, quantization points, rounding, borders). Layer compositing follows the user's decision (float math, like paint.net 5.2's FP32 compositor): the oracle is an f64 spec, and the 3.36 integer blend is a documented cross-check, not the gate. Ops whose target is legacy 3.36 behavior emulate its integer stages exactly. |
| 3 | No runnable OpenPDN exists, so "matches OpenPDN vectors" would test a port against itself. | OpenPDN is .NET 3.5 WinForms with no build; this Mac has no .NET | New milestone M03 builds an OpenPDN pixel-code oracle under .NET 8 in the Linux VM (pixel code plus stubs; no UI), and commits its vectors. |
| 4 | Captures cover effects only; tools are hard to automate; paint.net 5.2 is close to release and would change results if it auto-updates. | 5.2 beta notes (FP32 compositing, 8 new effects) | Pin paint.net **5.1.12** from the portable ZIP. M02 captures the whole effect catalog with a parameter matrix in one committed batch. Tools (brush, shapes, lines, text) use our own reviewed goldens plus geometry tests, never capture pixels. |
| 5 | wgpu sets `CAMetalLayer.colorspace` on every configure (fixed named spaces), so a document-profile tag gets overwritten. | `wgpu-hal/src/metal/surface.rs` | A presenter go/no-go spike (M09) decides between a lookup-table path (document → display profile, layer tagged with the display space) and a Swift-owned IOSurface presenter. Both must pass 200 resizes, screen moves and color charts. |
| 6 | Apple GPU shaders compile with fast math, and threshold ops flip on 1-ULP differences. | wgpu `metal/device.rs` | GPU kernels use integer math for thresholds and rank choices, CPU-precomputed lookup tables for weights and trig, `rgba8uint` storage with the shared rounding helper. Discrete ops define parity as "at most N differing pixels" in the target table. |
| 7 | A fixed `halo` cannot express global effects (Auto-Level, Levels, Quantize, warps, PatchMatch); wgpu default limits are 8192 px and 256 MiB. | `limits.rs`; histogram math | `EffectSpec` gains `prepare()` (analysis), `required_input(rect)`, pass kinds (pointwise, neighborhood, reduction, warp, iterative), and a working space. Request the adapter's real limits; tile sources wider than 16384. |
| 8 | `Arc` tiles cannot also move between Resident, Compressed and Spilled; strong counts are not a residency signal. All current-state tiles resident breaks on 8 GB (a 100 MP × 20 layer case is 7.45 GiB). | Arithmetic | Stable `TileId`s in a storage manager with pin counts, byte counts, checksums and last-use. Current-state tiles page too; one global memory budget covers pixels, history, previews, scratch and GPU caches. |
| 9 | Premultiplying everything loses RGB under zero alpha, which Invert Alpha and the wand's Straight mode need. | paint.net wand docs | Pixels stay straight in storage and in color adjustments; premultiply only for mixing and filtering. `None` tile = exactly transparent black; other zero-alpha colors are kept. Persistence and history tests compare all bytes. |
| 10 | Polygon-only selection loses soft masks (remove background, antialiased wand). | Design analysis | `SelectionSource = Geometry(PolygonSet) or Coverage(MaskGrid)`; contours only for marching ants. No selection, empty selection and Select All are distinct states. |
| 11 | Jobs need identity checks, and the preview transaction mechanism is needed long before Line/Curve. | Design analysis | Every job carries document id, base revision, layer id, selection revision, preview session id and parameter generation; mismatches never commit. Preview sessions and transactions move to M10. |
| 12 | `catch_unwind` at FFI entry points does not cover actor, rayon or render threads; callback re-entry can deadlock. | Design analysis | Catch at job and frame boundaries too; install a wgpu error handler; callbacks may not call back into the engine; explicit detach, close and shutdown order. |
| 13 | The 16× supersampled coverage oracle is off by up to 7.9/255. | Measured | Antialiasing references use exact analytic area coverage in f64. |
| 14 | Pinta images are Pinta's own Cairo output on one opaque input, with a ±2 pass rule and 7 of 14 blend modes. | `Utilities.cs` | Pinta is a weak cross-check (±2) only for effects Pinta did not change, plus our own alpha inputs. |
| 15 | Clock-seeded 3.36 effects (Add Noise, Frosted Glass, Clouds) have no repeatable output. | Source lines | Seeded own goldens plus statistical checks (mean, variance). |
| 16 | OpenPDN's `.resx` and `.png` resources are CC BY-NC-ND, and the GPC clipper is non-commercial. PatchMatch's sample code is research-only. | OpenPDN `License.txt` | Never copy `.resx` strings, `.png` assets or GPC code. Implement PatchMatch from the paper. M02 commits a file-level allowlist. |
| 17 | Five OpenPDN paths and two method names in MILESTONES.md were wrong. | GitHub tree API | Fixed (Selection, MoveTool, GradientRenderers, RecoloringTool, TileEffect, Bicubic/BilinearFitSurface). |
| 18 | The dependency graph did not gate release on 26 milestones; Phase 1 needed PNG before M11; M09 needed the presenter. | Graph script | New list: every milestone gates release; a minimal PNG reader lands in M04; dependencies rechecked. |
| 19 | Scope came partly from Pinta. Not in 5.1: Unfocus, Voronoi, Feather/Align/Outline Object. Missing: Temperature/Tint, Photo → Straighten, Median Blur, 8 resize modes, Auto Crop, canvas fill choices, copy/paste selection, document lifecycle (New, Save As, Revert, unsaved prompt), Open Recent, drag-and-drop, Color Profile dialogs, EXIF orientation reset, updates, command focus rules. | getpaint.net docs | Added to the new list. The final menu list comes from the M02 catalog of a running 5.1.12. |
| 20 | The runner sandbox cannot run Xcode or Swift; a sandboxed cargo cannot lock `target/`. | Workspace memory (Kelpi, QuickEdit, BeautifulWeather) | Swift (U lane) milestones run as native Opus builders. Rust milestones run through the runner with a clone-local `CARGO_HOME`; root reruns cargo, Metal and UI checks. |
| 21 | Hours were badly low. Astra: 320 to 568 h for the 13 hard milestones alone. | Estimates | Re-estimated: about 620 agent hours over 60 milestones. |
| 22 | Gates that a script cannot check (M27 latency, M41, M42 thresholds, M43 masks, M46 "looks right", M36 coverage) | Review tables | Replaced with Astra's precise gates (section 3 of `step0-astra.md`) in the new list. |

## Rejected or deferred

| Finding | Reason |
|---|---|
| Make compositing integer-exact to paint.net 3.36 | The user chose float math. paint.net itself moved to FP32 compositing in 5.2 because of those integer errors. The 3.36 integer blend stays as a documented cross-check. |
| paint.net may record each move or shape edit as its own history step before Finish (uncertain) | To be checked in the M02 catalog on real 5.1.12. The milestone gates follow whatever 5.1.12 does. |
