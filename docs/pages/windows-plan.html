How paint.net is used

  • Root runs its own pinned copy. Your running copy and its settings stay untouched, and processes stop by PID only.
  • We compare outputs and behavior. Its license forbids derivative works, so we never decompile it or copy its icons, help text or resources.
  • Captures try the public plugin API first, then UI Automation, then the old OpenPDN oracle.
  • Effects must reach ±1/255. An effect that cannot goes on a list for you, because a builder may not loosen a tolerance.
  • The product page and Store listing never name paint.net. W19 scans for it.
