# OpenPainter milestones (revision 2, after the Step 0 review)

60 milestones, 12 checkpoints (CP, one after every 5 milestones), 6 phases. About 620 agent hours. Revision 1 had 50 milestones and 300 hours; `docs/reviews/step0-decisions.md` explains every change.

Status values: `todo`, `doing`, `done (commit)`.

- **Lanes:** E = engine core (Rust: tiles, history, selection, tools, formats), O = ops and GPU (Rust plus WGSL), U = Mac app (Swift). E and O builds run through the runner on Sol. U builds run as native Opus builders, because the runner sandbox cannot run Xcode. At most 2 builders run at once (8 GB Mac).
- **★** = Astra deep-dive guidance exists in `docs/reviews/step0-astra.md` section 2. The builder brief includes it.
- **Common gate rules.** Every gate also requires:
  - every required test reports a nonzero case count
  - reference manifests pin versions and all parameters
  - every applicable pixel is compared, never only a mean
  - persistence and undo compare the full document state, every byte
  - performance numbers name the hardware, image size, parameters, warm or cold, and percentile
  - a GPU test fails if the GPU did not actually run
- **Oracles.** Each op's oracle comes from `tests/oracle/targets.toml` (made in M02): the OpenPDN harness (M03) for `legacy-3.36` rows, paint.net 5.1.12 captures for `pdn-5.1` rows, and our own reviewed goldens for tools.
- **Per milestone:** `cargo xtask check --tier fast` while building, then `--tier milestone`. Root reruns the checks.
- **Per checkpoint:**
  - `--tier checkpoint`, the Linux VM run, and the speed and size bars.
  - A review: Astra plus Opus when the batch had ★ work, one reviewer otherwise.
  - A diagram of what changed, and an update page.
  - The capability list for the checkpoint is committed before it runs.

## Dependencies and critical path

## Not in this version
- `.pdn` and PSD import; ORA, PDF or SVG export beyond `.opaint`; animated GIF and WebP frame editing.
- Layer masks, groups, adjustment layers, any non-destructive editing.
- 16-bit, float or HDR storage; CMYK and Lab editing.
- paint.net plugins or a public plugin API; scripting; batch processing.
- Windows, Linux or iPad UI (the engine stays portable and is tested on Linux).
- Printing (DPI is kept for later); cloud sync; App Store build; generative AI fill beyond PatchMatch and Vision.
- paint.net 5.2's new effects (Linocut, Mosaic, Pointillism, Stained Glass, Ordered Dither, Spherize, Waves, Halftone). The target is the pinned 5.1.12.
