How the build runs now

Up to 4 builders at once

Each wave's milestones run side by side, plus design work. Each builder compiles with 2 jobs so the 8 GB Mac keeps up.

Quick checks per milestone

A milestone is merged after the tests of the parts it changed pass on the Mac. No Linux run and no review at this step.

Full checks at phase ends

When all milestones of a phase are merged: every test tier, 10,000 random cases, the Linux run, two reviews, a diagram and an update page.

M02 no longer blocks

The Windows PC is still unreachable. Mockups use paint.net's public docs, and effects start from the paint.net 3.36 reference. The 5.1 screenshots are added when the PC works (dashed lines).
