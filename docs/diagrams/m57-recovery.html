OpenPainter · M57 · crash recovery

How an edit becomes a recovery record

A new writer thread copies each open image to a recovery folder after edits stop for 30 seconds (never more than 2 minutes behind). Each file is written to a temp name, synced, then renamed, so a crash at any point leaves the last complete record. After a crash, the next launch finds the record and offers to recover it.

Write order

Snapshot temp file, sync, rename, sync the folder. Then the manifest the same way. Only then is the old snapshot deleted and the revision reported. The manifest holds the snapshot's checksum, so a half-written snapshot is never chosen.

When a write fails

The error shows in the status bar and in a sheet. The previous saved file and the previous record stay readable. A failed save leaves the image marked unsaved.
