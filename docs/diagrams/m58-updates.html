OpenPainter · M58 · updates and release build

How a signed update reaches the app

M58 adds Sparkle 2 for Check for Updates. The feed and every update must carry an EdDSA signature that matches the key built into the app. No real key exists yet; until M60 adds one, the menu item only says updates are not set up.

Release build

The engine is now built as a static library with full link-time optimization (it never actually ran before). Swift uses whole-module optimization and dead-code stripping. The app went from 14.6 MB to 10.75 MB, including Sparkle.

Launch

GPU effect pipelines compile on first use; launch builds only the canvas pipeline. Median launch to a usable canvas: 0.75 s on a quiet Mac, 1.2 s under heavy load (budget 3 s).

Checked by script

scripts/perf-check.sh fails on app size over 75 MB, launch over 3 s, any early effect pipeline, or a 10% regression from the recorded baseline.
