# OpenPainter

A simple, fast photo editor for the Mac, in the spirit of Paint.NET. The engine is written in Rust so it can later run on Windows and Linux; the Mac app is Swift.

Status: in development. See `docs/PLAN.md` for the plan and `docs/MILESTONES.md` for progress.
